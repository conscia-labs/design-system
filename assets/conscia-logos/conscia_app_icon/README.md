# Conscia app icons

These app-icon assets use the official Conscia symbol geometry from
`src/primitives/brand-icon.tsx`.

| Appearance | Tile | Symbol |
| --- | --- | --- |
| Light | `#FFFFFF` | `#1E0721` Conscia burgundy |
| Dark | `#17191C` design-system dark canvas | `#FFFFFF` |

The SVG and PNG files are 1024 × 1024. The PNGs have transparent corners
outside the rounded-square tile, which lets iOS and macOS apply their own
icon masking cleanly. The `.icns` files are macOS-ready exports.
